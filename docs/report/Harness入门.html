02 HARNESS 介绍

Harness 介绍

Agent = Model + Harness

核心思想

模型已经会调用工具、会规划任务。
怎么让它安全、有效、正确地达成目标？

Agent = Model智能 + Harness控制

答案在模型之外：记忆、上下文、边界和能力
由 Harness 这一层统一负责。

01
Agent 运行框架 模型和工具交替推进，直到任务完成。
主循环流式输出取消与超时 并行工具调用步数上限子代理
02
上下文管理 控制模型每一步能看到什么、能看多久。
提示词装配变量插值运行时注入 历史裁剪自动压缩token 预算前缀缓存
03
工具与能力管理 所有对外动作都从这里经过，可校验、可拦截、可替换。
工具注册表schema 校验执行管线 审批沙箱能力接缝 插件 / MCP结构化错误
04
会话与持久化记忆 一切发生过的事都可查、可续、可分叉。
事件日志历史投影崩溃修复 resumeforkfollow 长期记忆审计导出
模型负责智能，Harness 负责让智能可靠地落地。 ← 返回封面 Esc 关闭弹窗

运行主流程

主流程

处理 决策 终止
环境初始化加载插件 · 恢复会话
用户提问turn/start
上下文装配提示词 · 裁剪 · 压缩
请求模型流式输出 · 做出决策
最终答案assistant/message
会话结束turn/end · 可 resume
审批 / 沙箱只读自动放行，写操作需要确认
工具执行并行 · 超时 · 异常结构化
结果回填 + 写日志tool/result → 事件流
结构化终止步数上限 · 超时 · 取消
有工具调用 无工具调用

结果、拒绝、错误都会回填给模型再走一步；超过步数上限走结构化终止。
