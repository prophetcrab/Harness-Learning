# report

阶段验收报告、代码精读结论、真实 API 测试结果等**分析类文档**放这里
（`docs/decisions/` 放决策记录，两者分开）。

命名建议：`P<N>-<主题>-<日期>.md`，例如 `P4-concurrency-and-real-api-2026-10-19.md`。

## 报告页：Harness 入门

`Harness入门.html` 是一套 16:9 的讲稿页面（封面 + 章节页 + 六个交互演示）。
**这一个文件夹里就是与报告有关的全部代码**，不依赖 P0–P4 的任何模块。

- `Harness入门.html`：页面本体，纯 CSS + 原生 JS，无外部依赖
- `server.py`：本地服务，静态托管本目录；同时提供 DeepSeek 代理（`/api/chat`）
- `run.bat` / `run.sh`：启动器

### 启动

```bash
python docs/report/server.py          # http://127.0.0.1:8765/
python docs/report/server.py --open   # 顺手打开浏览器
```

也可以双击 `run.bat`，或在 Git Bash 里 `./run.sh`。

只双击 `Harness入门.html`（`file://`）也能看页面，但聊天演示不可用——
浏览器不能直接带密钥请求模型，必须走 `server.py`。

### 聊天演示（真实 API）

弹窗「聊天页面」直接就是真实对话：输入问题、回车发送，回复来自 DeepSeek；
右侧显示本次请求实际携带的消息（最多 6 条），底部显示 token 用量。

### AI 工作流演示（模拟数据 + 真实 API）

弹窗「AI 工作流」是**固定五节点**的流程，其中两个模型节点真实调用 DeepSeek：

| 节点 | 数据来源 |
|---|---|
| 01 输入 | 页面里写死的模拟工单（林女士 / 订单 A-1029 / 重复扣款 128 元） |
| 02 模型 · 抽取 | 真实调用，要求只返回 JSON（`order_id` / `refund_amount` / `reason` / `customer`） |
| 03 模型 · 生成 | 真实调用，按抽取结果写 80 字以内的客服回复 |
| 04 格式校验 | 本地代码：字段类型、金额为正、长度上限、禁用词 |
| 05 交付 | 本地拼装最终 JSON 并展示 |

流程路径和输出格式由前端写死，模型只在蓝框节点里工作——这正好演示了
「AI 工作流」与「Agent 智能体」的区别：前者不会自己改道。校验失败时节点会标红并停在原地。

### Agent 智能体演示（真实循环）

弹窗「Agent 智能体」是一个**真的 agent 循环**，不是动画：每一步都由 DeepSeek
返回一个 JSON 决策，前端据此在内存工作区里执行工具，再把结果作为下一条消息
喂回模型。

| 工具 | 行为 |
|---|---|
| `read_file` | 读取内存工作区里的 `billing.py` / `README.md` |
| `write_file` | 整体覆盖写入（模型得给出完整文件内容） |
| `run_tests` | 跑内置的三条验收：正常退款、重复退款、未支付订单 |
| `finish` | 模型认为完成时调用，结束循环 |

初始 `billing.py` 缺少重复退款判断，所以模型必须先读、再改、跑测试，
失败后再改——这就是「走一步、看一步、再决定下一步」。步数上限 8 步，
到顶会停并提示真实 agent 需要步数预算。重置会清空工作区和对话历史。

工具全部在浏览器内存里执行，不碰磁盘，也不会真的运行任何命令。

密钥只在服务端读取，页面拿不到：

- 服务端从**项目根** `.env` 读取 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、
  `DEEPSEEK_BASE_URL`（环境变量优先）；
- 浏览器只调用同源的 `/api/chat`，响应里只有回复与 token 用量；
- 改完 `.env` 不需要重启，下一次请求会重新读取。

接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/status` | 是否已配置 key、当前模型与接口地址 |
| `POST` | `/api/chat` | `{"messages": [...], "max_tokens": 512}` → `{"ok": true, "reply": "...", "usage": {...}}` |

`server.py` 同时兼容旧地址 `/docs/report/Harness入门.html`，方便已经打开的标签页直接刷新。
